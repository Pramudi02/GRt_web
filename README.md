# GRT Travels & Tours Website

This is the official website for **GRT Travels & Tours**, designed to promote travel and tour services for the client. The website is built using **HTML**, **CSS**, and **JavaScript**. It showcases the travel packages, services, and other essential information for customers.

## Live Site
You can view the live website at:  
[**https://www.grttravelsandtours.com/**](https://www.grttravelsandtours.com/)

## Technologies Used:
- **HTML** - For the structure and content of the website.
- **CSS** - For styling and layout.
- **JavaScript** - For interactivity and functionality.

## Features:
- User-friendly interface for easy navigation.
- Information about travel packages and services.
- Contact forms and other essential sections.

## Installation:
To run the website locally:
1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/grt-travels-and-tours.git
    ```
2. Open the `index.html` file in any browser.
